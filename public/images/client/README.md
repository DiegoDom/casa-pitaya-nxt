# Casa Pitaya — Satoshi Logo Assets

These lockups use the project's Satoshi Variable font:
- `Satoshi-Variable.ttf`
- `Satoshi-VariableItalic.ttf`

## Spacing adjustment
The original Stitch HTML used:
- Wordmark: `tracking-[0.08em]`
- Subline: `tracking-[0.24em]`

For Satoshi, these assets use a more compact optical treatment:
- Wordmark: `0.04em`
- Subline: `0.14em`

The symbol geometry/colors are preserved from the Stitch SVG.

The SVGs reference `Satoshi` by family name; when used in the Next.js app, load the font from `/fonts/Satoshi-Variable.ttf`.
